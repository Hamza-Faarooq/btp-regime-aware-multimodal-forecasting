\section{Conclusion and Future Work}\label{ch:conclusion}
On this NIFTY/SPY benchmark, the strict chronological results identify the price-only LSTM as a strong baseline. Adding 768-dimensional FinBERT embeddings reduces Macro-F1, while a three-probability sentiment input has a higher point estimate but no reliable overall gain. Adding a regime label to the price-plus-embedding model also does not yield a reliable overall improvement. In the February--April 2020 stress window, no news-related difference from price-only is distinguishable from zero, but the 50-row sample is too small to exclude moderate effects. Looser evaluation protocols do not systematically inflate performance; the regime-only model is the clearest exception. Because protocol test samples differ, the observed gaps cannot be interpreted as pure leakage effects.

\begin{keybox}
\textbf{Take-aways.}
(i) Evaluate against a strong price-only baseline and a random-guess floor; a majority baseline is a misleading Macro-F1 floor.
(ii) Fit all learned preprocessing and regime assignments using training data only for the primary evaluation.
(iii) Treat the embedding overfit pattern as a result for this setup, not a universal property of financial text; compact summaries merit further controlled testing.
(iv) Report every model and comparison run, and treat isolated significant intervals as hypotheses.
\end{keybox}
\subsection{Future Work}
\begin{itemize}
\item \textbf{Gated fusion (M7).} A regime-conditioned gate between the price and news embeddings is implemented but not evaluated; it would test whether news can be made useful conditionally.
\item \textbf{Lagged window ($\mathrm{LAG}=1$).} Re-running the pipeline with windows ending one day earlier, as in the benchmark's own prompt, would show how sensitive the conclusions are to the timing convention.
\item \textbf{Stronger regularisation of the news branch,} e.g.\ low-rank projections, PCA, or weight decay and dropout search on validation data only.
\item \textbf{More assets and periods,} and a block bootstrap that respects autocorrelation.
\item \textbf{Publication-time stamps for headlines} to remove the main timing uncertainty.
\end{itemize}
